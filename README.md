# 🛍️ Enterprise Shopping Cart Widget

A high-converting, modern, fully responsive shopping cart frontend module built with vanilla HTML5, modular CSS3, and robust ES6+ JavaScript. Designed with global enterprise standards in mind, featuring seamless state updates, dynamic calculation flows, promo code validation, and a sleek dark-mode aesthetic.

## ✨ Features & Upgrades

- **Dynamic State Management:** Real-time calculation of item subtotals, item quantity metrics, shipping rates, and grand totals without page reloads.
- **Interactive Promo Engine:** Built-in voucher validation logic (try code **`SAVE15`** for 15% off).
- **Graceful Empty State UX:** Automatically transitions to a polished empty state view with a "Start Shopping" call-to-action when all items are removed or cleared.
- **Event Delegation Architecture:** Optimized JavaScript event listeners handling dynamic item rows efficiently.
- **Full Responsive Adaptation:** Transforms seamlessly from a multi-column desktop layout into a compact, thumb-friendly mobile configuration.
- **Security & Trust Indicators:** Integrated SSL encryption badge and clean action triggers.
